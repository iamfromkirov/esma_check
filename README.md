# Проверка МРМ (ConnectionCheck)

Android-приложение для диагностики соединения. Показывает:

- IMEI телефона (с оговоркой для Android 10+, см. ниже);
- статус GPS, координаты, точность, источник данных (GPS / Network / Fused), число спутников;
- проверку на Fake GPS;
- Wi-Fi: текущая сеть и список найденных сетей;
- доступность узлов (TCP + HTTP): МТС (`mts.ru`), МРМ (`10.146.130.17:80`), ЕСМА Центр (`10.146.130.75:7780`);
- SIM-карты: слот, оператор, какая SIM по умолчанию для данных / SMS / звонков и через какую SIM идёт соединение;
- отправку компактного отчёта по SMS (напрямую или через приложение SMS).

Внешних библиотек нет, только Android SDK. minSdk 24 (Android 7.0), targetSdk 34.

## Сборка на GitHub

1. Создайте репозиторий и загрузите в него всё содержимое этой папки (включая скрытую `.github`).
2. Откройте вкладку **Actions**: workflow **Build APK** запускается при каждом push. Можно запустить вручную (**Run workflow**).
3. После окончания откройте запуск, внизу в **Artifacts** скачайте `ConnectionCheck-debug-apk`.
4. Если создать тег вида `v1.0`, APK автоматически прикрепится к странице **Releases**.

Установка: скопируйте APK на телефон и разрешите установку из неизвестных источников.
APK подписан отладочным ключом, этого достаточно для установки «вручную».

## Ограничения Android

- **IMEI.** Начиная с Android 10 обычные приложения не могут читать IMEI, система выдаёт `SecurityException`.
  Приложение в этом случае показывает пояснение и Android ID; IMEI можно узнать набором `*#06#`.
  На Android 9 и старше IMEI читается после выдачи разрешения «Телефон».
- **Fake GPS** определяется эвристически: флаг mock у координат, приложение, выбранное в настройках
  разработчика как источник фиктивных координат, установленные приложения с правом `ACCESS_MOCK_LOCATION`,
  GPS-fix без единого спутника в решении. Идеальной защиты от подмены не существует.
- **Wi-Fi.** Список сетей требует разрешения на геолокацию и включённой геолокации в системе.
  Android ограничивает частоту сканирования (около 4 раз за 2 минуты), поэтому данные могут быть чуть старыми.
- **Узлы 10.146.130.x** доступны только из соответствующей сети (корпоративный Wi-Fi или VPN).
  Любой HTTP-ответ (даже 401/404) считается «доступен», отдельно показывается, открылся ли TCP-порт.
- **SMS** уходят через SIM по умолчанию для SMS и тарифицируются оператором. Перед отправкой показывается
  текст и запрашивается подтверждение. SMS-отчёт только латиницей, чтобы уложиться в один-два сегмента.
  Если на телефоне заблокирована отправка SMS из сторонних приложений, используйте кнопку «SMS через приложение».

## Структура

```
settings.gradle.kts, build.gradle.kts, gradle.properties
app/build.gradle.kts
app/src/main/AndroidManifest.xml
app/src/main/java/com/example/connectioncheck/MainActivity.kt
app/src/main/res/{layout,values}/...
.github/workflows/build.yml
```

Локальная сборка: `gradle assembleDebug` (нужны JDK 17 и Android SDK 34) или открыть папку в Android Studio.
Список сайтов меняется в начале `MainActivity.kt` (переменная `targets`).
